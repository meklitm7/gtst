## 🔧 Git & GitHub

  
### 🗂️ Git

Git is a **version control tool**. It detects changes and stores them as versions (`v1`, `v2`, ...). These versions can be stored on a remote server like GitHub.


> Created by the **Linux community**.

### ☁️ GitHub

GitHub is a **cloud-based Git hosting platform** — essentially a remote server used to access your documents remotely.

### 🔑 Keywords


| Term | Meaning |

|------|---------|

| **Repository** | A folder |

| **Push** | Uploads data to GitHub |

| **Pull** | Downloads changes and integrates them with previous ones |

| **Clone** | Downloads the repository |

| **Commit** | Saves staged changes to the local repository (use `push` to upload to GitHub) |

| **Add** | Adds changes from the working directory to the staging area (index) |

| **Status** | Checks if a change is committed or not |

| **Log** | Shows commit history (date & author) |

## 🛡️ Intro to Cybersecurity

**Cybersecurity** is the process of preventing digital attacks on systems, programs, and networks.


🎯 **Aim of cyber attacks (hacking):** to access, change, and destroy sensitive information.

### 🔑 Keywords

- **Hacking** — exploiting vulnerabilities and using them in an unauthorized way

- **Ethical hacking** — finding vulnerabilities and reporting them to the organization

- **Hacker** — the person who performs hacking  

### 🎭 Types of Hacker (by Ethics)

| Type | Description |

|------|-------------|

| ⚫ Black Hat | Illegal |

| ⚪ White Hat | Ethical |

| ⚪⚫ Gray Hat | Combination of black and white hat |

### 🎓 Types of Hacker (by Skill)

| Level | Description |

|-------|-------------|

| Noob / Newbie | No knowledge of hacking |

| Script Kiddie | Uses scripts/programs made by others, usually for malicious purposes (e.g. stealing Wi-Fi using YouTube tutorials) |

| Hacker | Has knowledge but less experience |

| Elite / Pro Hacker | Has both knowledge and a lot of experience |

### ❓ Why Do We Learn Cybersecurity?

- To safeguard data

- To prevent cyber attacks

- To enhance security awareness

- To uncover vulnerabilities

### 💥 Why Hacks Happen


> **Attack = Motive (Goal) + Method + Vulnerability**

**Motive** includes things like info theft, revenge, and manipulation.

### 🔺 Elements of Info Security — The CIA Triad


| Principle | Meaning |

|-----------|---------|

| 🔒 **Confidentiality** | Preventing access to private/sensitive info by unauthorized people (e.g. data encryption) |

| 🧩 **Integrity** | Ensuring data isn't manipulated or tampered with — only authorized people can change it |

| ⏱️ **Availability** | The system is available 24 hours a day |

### 🧠 Skills to Become a Hacker

- Computer programming

- Computer networking

- System understanding (Linux, Windows)

### 🚶 Phases of Hacking

1. **Reconnaissance** — gathering info

2. **Scanning** — scanning for loopholes (weak points) using tools

3. **Gaining Access** — exploiting a vulnerability

4. **Maintaining Access** — creating a backdoor

5. **Clearing Tracks/Logs** — hiding evidence so the system seems untouched

## 🧪 Penetration Testing (Pentest)


Tests, measures, and evaluates system security by finding vulnerabilities, evaluating security measures, and writing a report.

### ❓ Why We Need Pentesting

- To control the system

- To prevent threats

- For upgradation of infrastructure

### 🧷 Types of Pentest

| Type | Prior Knowledge | Tests As |

|------|------------------|----------|

| **Black** | None | Attacker |

| **White** | Full | Developer |

| **Gray** | Limited | User |

## 🏳️ Cyber Field Terms

  
- 🔴 **Red Teaming (Offensive)** — tests the system by pretending to be a black hat hacker

- 🔵 **Blue Teaming (Defensive)** — defends the system by blocking vulnerabilities before attackers strike

- 📋 **Security Audit** — comprehensive evaluation of an organization's info systems, security controls, and procedures; assesses compliance with standards, policies, and regulations

- 🔍 **Vulnerability Assessment** — automated scanning, manual testing, and analysis to identify weaknesses
